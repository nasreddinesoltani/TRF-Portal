# Goal

Implement the World-Rowing-style two-step results status (UNOFFICIAL → OFFICIAL) that already half-exists in the schema, surface both statuses everywhere, and add a per-event-group "REVISED" flag set from the results entry page and rendered in the exported PDF (red "REVISED" in the header line, between "Results" and the category/boat code).

Current state confirmed by exploration: `resultsStatus: pending|unofficial|official` exists on Competition but nothing ever writes "unofficial"; per-group `OfficialResult` documents have no status/revised fields (only `revision`/`locked`/`publishedAt`); the entry page's "Official Publish" button only saves + marks the race complete; the "Official results workflow" panel in CompetitionRaces publishes groups (upsert by `competition + eventGroupId`); the public results endpoint serializes full group documents, so new fields flow through automatically.

# Backend

## 1. `Models/officialResultModel.js`
Add group-level fields: `status: enum ["unofficial","official"], default "unofficial"` and `revised: Boolean (default false)` + `revisedAt: Date`.

## 2. `Controllers/competitionRaceController.js`
- `publishOfficialEventGroupInternal`: payload gains `status` (default `"unofficial"`; **preserve** the existing doc's status and `revised`/`revisedAt` on republish so an official group stays official and a REVISED marker isn't lost). After upsert, sync the competition: if group status = "unofficial" and `competition.resultsStatus === "pending"` → set `"unofficial"`; if "official" → `"official"` (+ `resultsPublishedAt` if unset).
- New handler `markOfficialEventGroupResults`: `POST .../official-results/:eventGroupId/official` → sets group `status: "official"`, sets competition `resultsStatus: "official"` (+ `resultsPublishedAt`). 404 if group missing.
- New handler `setEventGroupRevised`: `POST .../official-results/:eventGroupId/revised` body `{ revised: boolean }` → sets `revised` / `revisedAt`; 404 if group missing (message "Publish the results first").
- `listOfficialResultGroups`: add `status revised` to the `.select()` so the admin UI can show them.

## 3. `Routes/competitionRaceRoutes.js`
Register the two new POST routes (same `protect` + `allowRoles("admin","jury_president")` as the others).

## 4. `Controllers/competitionController.js` (`applyStatusUpdates`)
When `resultsStatus === "official"` is set via the competition-wide "Mark Official" button, also `OfficialResult.updateMany({ competition }, { status: "official" })` so published-group badges agree with the competition-level switch.

Note: groups already in the DB without the field are treated as "unofficial" by convention (`group.status || "unofficial"`) — no migration needed.

# Admin frontend

## 5. `pages/CompetitionRaces.jsx` — Official results workflow panel
- Group selector options: append ` - official` / ` - unofficial` (from `group.status`) and ` - REVISED` when `group.revised`.
- Rename the existing "Publish official" button to **"Publish (Unofficial)"** (same endpoint; creates/updates the group as unofficial).
- New **"Mark official"** button (enabled when the selected group is published) → `POST .../official-results/{eventGroupId}/official`, then refresh groups + preview.
- Show a REVISED indicator next to the "Published revision N" label when the selected group is revised.

## 6. `pages/RaceDetail.jsx` — results entry page
- Rename the "Official Publish" button to **"Save & Complete"** (it saves + marks the race completed; publishing happens in the workflow panel).
- Add a **"Mark as revised"** checkbox in the results entry panel, shown when the race's `eventGroupId` is published. Data source: fetch `GET .../official-results/groups` when the entry panel opens and match `race.eventGroupId`; the checkbox initialises from the group's `revised` state and also shows the group's current UNOFFICIAL/OFFICIAL badge.
- On save: after the lanes PUT succeeds, if the group is published, call `POST .../official-results/{eventGroupId}/revised` with the checkbox value.

# Public frontend

- Per-group badge in the event card title row (next to the event label): **UNOFFICIAL** (amber) or **OFFICIAL** (green) from `group.status || "unofficial"`, plus a red **REVISED** chip when `group.revised`.
- Restyle the existing plain-text resultsStatus line (competition level) as a matching pill.

## 8. `public.css`
New badge variants: `.pub-badge--unofficial` (amber), `.pub-badge--official` (green), `.pub-badge--revised` (red).

# PDF — `lib/publicResultsPdf.js`

## 10. Status box
The box under each table becomes status-aware: UNOFFICIAL → "Unofficial Results — subject to jury verification."; OFFICIAL → "Official Results - Times are final."; when revised, append "Results revised after publication."

## 11. Plumbing
- `generateRaceResultsPdf`: read `group.status` / `group.revised` (already passed in whole) → `renderEventSheet` → header + status box.
